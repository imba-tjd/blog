# Spark

是MapReduce的替代，实现了更多算子。不是Hadoop的替代。

## 安装

* https://dlcdn.apache.org/spark/spark-3.5.5/spark-3.5.5-bin-hadoop3-scala2.13.tgz https://mirrors.aliyun.com/apache/spark/
  * 如果本地没有Hadoop，则要下with hadoop的，实际带有hadoop-client的包，是必须使用的。只有本地有Hadoop才能下without的，设置HADOOP_HOME
  * Win下需要：https://github.com/globalmentor/hadoop-bare-naked-local-fs/issues/2 现象是Hadoop需要%HADOOP_HOME%\bin\WINUTILS.EXE，这个东西最新的预编译只到Hadoop3，用此仓库后能解决，虽然还是报错但不用管
* 目前最高支持jdk17，再高会报错
* 如果已有共享文件系统，如NFS和S3，则可以不用Hadoop；如果数据储存在HDFS上，则要。不清楚纯本地文件系统行不行
* 不用管：Unable to load native-hadoop library for your platform... using builtin-java classes where applicable

### Win

https://github.com/globalmentor/hadoop-bare-naked-local-fs/issues/2

1. 下载 https://repo1.maven.org/maven2/com/globalmentor/hadoop-bare-naked-local-fs/0.1.0/hadoop-bare-naked-local-fs-0.1.0.jar 到jars里。
2. 在jars里创建core-site.xml内容是`""`，创建hdfs-site.xml内容是`<property><name>fs.default.name</name><value>com.globalmentor.apache.hadoop.fs.BareLocalFileSystem</value></property>`。
3. 设置HADOOP_HOME为Spark的目录。在bin里创建空txt重命名为WINUTILS.EXE。

## 体系结构、角色

* Driver：具有main()和SparkContext对象，连接集群提交Job。应与工作结点在同一局域网内（deploy-mode=默认client）；如果其他网络的程序要提交任务应让那些程序和Driver RPC，而不是把Driver放到别的网络
* Manager：资源管理器，支持多种实现，包括standalone YARN k8s
* Worker：一个Application在每一个worker里都有一个Executor（里面有一个Cache），可以运行多个Task
* Application：用户代码，包括依赖项，一般是uber jar。概念上包括Driver和Executor
* Job：如save、collect，会产生多个Task并行计算。Stage：比Task大比Job小，是一组Task，类似于map和reduce的概念
* 主要API：之前叫 弹性分布式数据集 Resilient Distributed Dataset(RDD) 不推荐用了。现在叫Dataset（在pyspark中也叫DataFrame），要看“SQL programming guide”。都是强类型的，但后者性能更好

## 服务端

* 配置文件：conf文件夹中有一些template文件
  * 系统环境变量：SPARK_HOME。如果用脚本启动则可选
  * spark-env.sh：export k=v。master和worker的都能用同一份设置，按k区分了
    * SPARK_DAEMON_JAVA_OPTS
  * https://spark.apache.org/docs/latest/configuration.html
* 启动
  * ./sbin/start-master.sh  日志输出 spark://HOST:7077
    * 默认以daemon运行，改为前台：SPARK_NO_DAEMONIZE=true
    * HOST默认为 hostname 命令的结果，不是localhost。PORT必须填，客户端连接时没有默认值
  * ./sbin/start-worker.sh master-spark-URL或配置SPARK_MASTER_HOST
  * start-all.sh：在master节点上的 conf/workers文件 里一行一个worker主机名，必须先建立好免密ssh认证
  * 都不支持win
* Web UI：start-master是8080，worker是8081，REPL是4040
* 测试：spark-submit run-example --master spark://HOST:7077 SparkPi 10

## Application

* REPL：spark-shell是scala，pyspark是py
  * 如果不指定--master则以local[*]模式，括号内代表要使用的线程数，星号代表逻辑cpu数
* 提交到集群
  * java：spark-submit --class Main --master xxx uber.jar，将Spark和Hadoop列为provided依赖
  * py：如果安装了pyspark包，可以直接运行py文件。若用submit且有多个文件或有第三方依赖，见user_guide/python_packaging
* 示例：examples/src/main/python/pi.py
* 文档：https://spark.apache.org/docs/latest/api/python/getting_started/

```py
from pyspark.sql import SparkSession
from pyspark.sql import functions as sf

spark = SparkSession.builder.master("...").appName("SimpleApp").getOrCreate()
# pyspark：Spark context available as 'sc', SparkSession available as 'spark'.

textFile = spark.read.text("README.md").cache()
linesWithSpark = textFile.filter(textFile.value.contains("Spark"))
print(linesWithSpark.count())

spark.stop()
```
