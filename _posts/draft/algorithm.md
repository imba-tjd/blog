## 技巧

* 用max()替代if，记录最大值：`if cur > m: m = cur` -> m = max(m, cur)；限制下限：`if x < limit: x = limit` -> x = max(x, limit)
* 整数的ceiling：(a + b - 1) / b
* 同时遍历两个长度不同的序列：if len(A) > len(B): return f(B,A) 保证A的长度更短，后续取下标时不用再判断是否越界；如果按更长的遍历，也可以在后续只判断短的是否越界
* 处理字符串题目时看能不能用正则
* 做类似reduce时，以下标0的元素为初始状态，从下标1开始遍历
* 如果一个数据范围是10^9，那几乎肯定不能去遍历它。一般另一个数据量是10^5，可能要先对它排序再遍历
* 若数据分成两部分，一部分量级允许暴力，另一部分量大，且又看不到结果，可以if(n<=1e5) 暴力 else 正常解。即一个题目里同时写两种算法，这样暴力过了也有分，防止爆0

### 一种避免goto的方法

```
A:
    f1()
B:
    if c1 goto A
    f2()
    if c2 goto B
end

改成：
f1()  手动重复一次，c1就变为入口条件了
do {

    f2()

## 基础理论

* 递归：①切蛋糕思维，找重复 —— 子问题，找变化量 —— 作为参数，找边界 —— 设计出口。②找递推公式、等价转换
* 遍历树
  * 递归函数一般有返回值
  * 终止条件一般是if(root==null)return null即什么也不做，因为逻辑不一定要在终止时做，剩下的部分root都不为null
  * 如果涉及修改，一般有if(...)l=R(l); if(...)r=R(r); return root; 即即使未修改，也会进行赋值，且即使答案只在一边中也会遍历整个树一遍
  * 处理自身的逻辑若在递归前则是先序遍历，后则是后序遍历
  * 剪枝：if(l ...)return R(r)

### 循环不变式

1. 初始化：循环的第一次迭代前为真
2. 保持：如果循环的某次迭代前为真，那么下次迭代前仍为真
3. 终止

当想“模拟”一步步检查条件和下一步行动时，看看能不能想高层一点，用循环想清楚起始和结束条件。\
当存在双重循环时，看能不能内层依次多用几个循环，使得内层完成后外层只是规模减小了，子问题仍然相同。

### 渐进记号Big O notation

* O表示渐进上界，Ω表示渐进下界，Θ表示渐进确界
* 求解递归式：代入法、递归树法（每递归一次产生一个子结点，结点总数是递归次数。如果每次规模/2，则高度是logn，如果合并一层的复杂度是n，则总复杂度是nlogn；如果合并是O(1)且产生2个子问题，则总复杂度是结点总数n；有重复子问题或剪枝才能更少，如规模/2但只产生1个新子问题如二分查找；如果每次规模-1但产生2个子问题则是2^n）、主方法
* log(n)：如AVL搜索，每次判断抛弃一半的树，即缩小一半search space。2^n：斐波那契数列（空间O(n)）、01背包。n!：排列问题，一开始有n的规模，会产生(n-1)个子问题，如八皇后
* Backtracking回溯问题：一些NP问题，像八皇后、背包。最坏复杂度就是无解的时候，因为想证明无解就得否定所有的解，即会考虑所有的可能成为解的情况。基本上就是指数或阶乘的复杂度

#### 代入法/公式法

* 失败时可以考虑**减去**一个低阶项
* T(n)=2T(n/2)+n -> O(nlogn)
* T(n)=2T(n/2)+c -> O(n)
* T(n)=2T(sqrt(n))+logn -> 令m=logn, O(mlogm)
* T(n)=9T(n/3)+n -> O(n^2)
* T(n)=T(2n/3)+c -> O(logn)
* T(n)=8T(n/2)+n^2 -> O(n^3)
* 幂方级数：比幂次高一阶 T(n)=1^3+2^3+...+n^3 -> O(n^4)
* 几何级数：与末尾项同阶 T(n)=1+2+4+...+2^n -> O(2^n)
* 收敛级数：O(1)
* 调和级数：O(logn)
* 对数级数：log1+log2+...+logn = log(n!) -> O(nlogn)

### Online在线雇佣

类似于选苹果的故事。在n个人中只雇佣一次，希望最大化质量，则做法为：选取一个正整数k<n，拒绝前面k个，雇佣其后面第一个比前面所有分数都高的人。k应取n/e，雇到最好的应聘者的概率至少为1/e。

重点：甚至连一遍遍历都没有，就做出选择。不是完美的，而是近似的。

### 分治法

1. 分解 (Divide) ：原问题分解为若干子问题，子问题是原问题的规模较小的实例
2. 解决 (Conquer) ：递归地求解子问题
3. 合并 (Combine) ：合并子问题

* 例子
  * 大整数乘法
  * 二分查找
  * 矩阵乘法
  * 归并排序
  * x的n次幂：分奇偶，n是偶数就是f(n/2)相乘，是奇数就再乘以x或f(n/2+1)*f(n/2-1)
  * 快速排序

### 滑动窗口

考虑窗口内的元素维护怎样的不变式，如何移动起始位置、结束位置。\
在移动过程中计算和记录所求内容直到结尾，如start往后移动时可能要减少状态值。\
一般用双循环，外层移动end，每次只动一步，能使得条件由不满足变为满足。\
内层循环当满足条件时多次移动start，往不满足条件的方向移动。

与双指针的区别：双指针可能跟踪两个不同的序列，可能从两边往中间移动。

## 位运算

* 异或可理解为（二进制的）不进位加法，就是加了之后丢弃进位
* 判断奇偶数
* (x-1)&x：消掉最低位的1。可用来计算有多少个1、判断是不是2的n次方（只有1个1）
  * 获得最低位的1：x-上一条。或x&-x，见lowbit
* 交换奇偶位：&b1010取出偶位，&b0101取出奇位，位移一下再或即可。实际int有32位，b1010...是0xaaaaaaaa，b0101...是0x55555555
* 纯小数转换为二进制表示：如0.625 -> 0.101。每次乘2，如果整数部分为1，就记1，并改成0，继续乘。可能无法精确表示。对应十进制整数转二进制每次除以2

### 序列中出现x次的y个数字

* 找出值在[1,n]的序列中唯一出现2次的数，其它数字只出现1次：把序列异或一遍成1个数，再手动异或一遍[1,n]，就消除了其它数
* 一个数出现1次，其余数出现k次，范围任意：把它们转换成k进制，做不进位加法累加（加了后%k），就能消掉其他数（k进制下出现k次类似于乘以10），再转回十进制
* 找出各只出现1次的2个数，其它数字都出现2次：先直接全部异或得到a^b。可以通过分组分别求出2个数。假设它俩分别是奇偶，那将序列里的值（不是下标）按奇偶分组就能分别求出，因为其它出现2次的数只能是奇数或偶数。如果最后一个二进制位相同，可以按第二位（最后不同的位）分组，因为两个不同的数二进制位一定不同，即a^b中为1的位
* 出现次数超过一半：记录val及其出现次数，如果下一个数也是val则count++，否则count--，直到0则换val。原理是将目标“抵消”其他数

### x数之和（解多项式整数方程）

以下除了 两数之和 只有一个结果，其它的都要处理多个可能的结果。\
除了 组合总和4 对顺序有要求，其它的对于不同顺序只算一个结果，那就要固定一个顺序，且若序列里含有重复元素还要去重。

* 两数之和：在序列中选2个元素，加起来等于给定的target。解法：遍历到x时，只需要后续再遍历到t-x即可，用set存。一次遍历即可完成
  * 变形：若序列已升序，可用双指针。一开始left和right分别指向数组两端。如果相加>target，说明应减小，则right--，因为中间任何一点都比left大。空间O(1)
* 三数之和：在序列中选3个元素，加起来等于0
  * 解法一：外层循环固定1个数，再按 普通两数之和 做，O(n^2)
  * 解法二双指针：先排序，外层循环固定1个数，再按 两数之和变形 做。如果==0，同时动，直到相遇，因为本题要求输出所有答案
    * 剪枝：固定的那个数>0则break，因为后面都>0。若nums[i]+nums[-2]+nums[-1]<0则continue，因为本轮后面都<0，但i继续增大可能达到0
  * 去重：当各元素值等于前面的时跳过。不能做成等于下一个时跳过，因为可能还没计算有效的就跳过了，如[1,1,-2]、[0,0,0]
* 四数之和：在序列中选4个元素，加起来等于target。解法：三数之和上再加一层for。不能剪枝“最外层>target结束”，因为target可能为负
* 四数相加：四个序列各取一个数，计算相加等于0的次数
  * 正解：分组。先二重循环AB两个序列，计算a+b存到map里，v是count；再二重循环CD，如果-(c+d)在map里，则结果加v。只需O(n^2 + n^2)
  * 原理：计算了a+b的所有可能取值，如果暴力循环，会重复计算c+d
* 组合总和3：在不重复序列中选k个元素，和为n。解法：回溯，从左往右取，递归时从下一个位置开始取（见组合算法）。无双指针或set的优化
* 组合总和：同上一条，但选任意多个且可重选。解法：回溯，没有递归层数的限制，仅当总和>target（或递归参数逐渐减小<0）才返回
* 组合总和4：同上一条，但不要求输出每个结果，而是输出“组合数”，实际题目要求不同顺序算不同方案，即“排列”。解法：完全背包，for j in range(0,target+1) for x in nums: if(j-x>=0) dp[j]+=dp[j-x]。初始化dp[0]=1没有实际含义但必须这么做，或理解为保证容量最初足够x时的方案为1

### 缺失的第一个正整数

特点是数字范围远大于序列长度，关键点是所求数必在[1,n+1]中（n为序列长度），超出此范围的数无意义。

* 第一种解决思路：先遍历一遍，将负数都改为-(n+1)，表示超范围；再遍历一遍，遇到绝对值小于n+1的数时，将对应的下标的值改为负数，表示模拟哈希表存在此数；再第三遍遍历第一个正数的
* 第二种解决思路：遍历遇到范围内的数时，与对应下标的数交换，否则设为-1；第二遍找下标不等于值的数

### 寻找峰值

假定数组两端是负无穷，中间一定有一个或多个极大值，求任意一个。

思路，二分：一开始的区间[0,n]一定包含峰值，取mid，关键就是怎么缩小区间使得区间中仍然包含峰值。结果是看mid和mid+1，如果<，说明是在上升，则区间变为[mid,n]；否则是在下降，[0,mid]

### 子数组、子序列

* 子数组：连续。子序列：不连续

#### 最大子数组和

例如：[13, -3, --25, 20, -3, -16, -23, 18, 20, -7, 12, -5, -22, 15, -4, 7]，18到12之和即为最大子数组。此问题中某些元素必小于0。

* 分治算法：取中点，任何一个子数列只有{完全位于左边、完全位于右边、跨过中间}三种情况，取三者最大值。前两者是原问题的较小规模，递归求解。第三个问题不是原问题，但容易求解，就是从中间往两边延伸，记录最大值
* dp：与常规化的不同。定义dp[i]为以nums[i]结尾的数组的最大子数组值，dp[i]=max{nums[i], dp[i-1]+nums[i]}，最后遍历一遍dp取最大值（不是返回dp[最后一个]）
* 滑动窗口+贪心：只需遍历一遍即可完成。从头开始加，记录最大的时候。如果加到了小于0就直接把前面的部分全部舍弃，因为当前评估的值会抵消掉之前所有的和，直接不要了（最大的还是要记录着）

衍生题目：全是正的而要算变化值最大的，则用后一个减去前一个，就会出负的。

衍生2，加油站：在一个循环数组中表示油量变化（有正有负），求一初始位置，使得车能跑完一圈；题目保证若有解（出发后油一直>=0）则唯一。\
解法（贪心）：若sum(arr)<0则无法跑完。若有解，从头累加，若<0，则从下一个位置重新开始。\
原理：对于已经过的区间，油量一直>0，若下一步<0，则从区间中任意一点出发更加无法到达下一步，因为从中间出发只会减少累积。

衍生3，一个全正数组，求元素之和大于target的长度最小的子数组：双指针，每次移动一步right，当区间和去掉left还大于target时不断去掉（即尝试去掉，保证区间始终大于target），记录区间长最小值

#### 最长递增子序列（LIS）的长度

如[1,4,2,3]的LIS是[1,2,3]。后面的递增序列不一定能刚好由前一个推出来，而是要再往前找。

* DP O(n^2)：用dp[i]表示**以第i个元素为结尾**的LIS的长度，且要遍历dp前面所有项才能得出当前项。全初始化为1因为单个数字也算递增。dp[i]=1+max(dp[j] if num[i]>num[j])
* DP从零开始的思路
  1. 始终保留前面的LIS内容。每次当cur>每个保留序列的最后一项时，添加进序列；若cur<任何末尾值，则直接添加。最后结果取保留序列长度的最大值
  2. 但实际上
    1. 不需要完整记录序列，只需记录最后一项即可，即[(last,len)]
    2. cur只需附加到大于末尾值的保留序列里最长的那个，因为给短的附加cur，二者最后一项都变为cur，单纯长度短无意义
    3. 对于相同的末尾值，可以保留长度最长的，但意义不大，如[1,5,4,3,2]
    4. 即使维护last有序二分定位，还是要挨个找len最大的
  3. 当不直接用cur，而是用num[i]间接使用时，就是DP解法
* 贪心+二分
  1. 对于相同长度的LIS，优先(仅)保留末尾值更小的那个，这样后续遍历更容易增长
  2. 题目数据的序列长度小于1000。用d[k]记录当LIS长度为k时的最小末尾值，d[1]=num[0]
  3. d是单调增的。不可能存在i<j且d[i]>d[j]，因为对于d[i]对应的序列，若保留前面的项，第i项取d[j]对应的值，就得到了长度为i且末尾值更小的序列，但没保留，与假设矛盾
  4. 算法：遍历nums。对于已有的d，若cur>d[-1]，则d.append(cur)，表示记录长度+1时的末尾值。否则cur处于单增序列d的中间，用二分找到d[x-1]<cur<d[x]的位置，令d[x]=cur。最终结果为len(d)

#### 最长重复子数组

有两个数组A B，求它们最长重复(公共)(连续)子数组的长度。

* 暴力：分别枚举A B下标i j作为重复子数组的起始位置，用k一同往后移动，若A[i+k]==B[j+k]且不超限则k++。复杂度O(n^3)
* DP：dp[i][j]表示以A[i]和B[j]结尾的最长重复子数组的长度，当A[i]==B[j]时，dp[i][j]=dp[i-1][j-1]+1，否则=0。初始化要计算A[0]与B和A与B[0]。或用另一种表示方法：dp[i][j]表示以A[i-1]B[j-1]结尾，则dp[0][j]和dp[i][0]都能初始化为0。可优化为滚动数组，因为只依赖上一行
* “滑动窗口”：A B的所有相对位置关系只有n+m种，即A保持不变，B从后往前滑动（B的首元素与A的某个元素对齐），以及反过来；其中一种对齐方式将最长重复子数组起始位置也对齐了。当确定A B的起始位置后，同时往后比较，遍历范围为二者长度的公共部分；如果当前位置不等，则计数=0，否则累加，这样即使最长重复子数组从中间开始也没问题。复杂度O((n+m)*min(n,m))
* 滚动哈希+二分：所求长度只可能是 [0,min(n,m)]。若所求长度为k，则存在长度为0<=j<=k的重复子数组，因为最长重复的其中一部分也是重复的。使用滚动哈希，能在线性时间内求出所有长度为j的子数组的哈希值，如果存在相等的，则表示满足，更新长度下限，否则更新长度上限。复杂度O((n+m) * log(min(n,m))

最长公共子序列（LCS）的长度：上面的DP解法，不等时不设为0，而是max(dp[i-1][j], dp[i][j-1])。它具有重叠子问题dp[i-1][j-1]。可以记忆化递归，而子数组却无法递归解决。

## 链表

* 链表反转
  1. 连续三个(指针)变量 pre cur next=cur.next cur.next=pre pre=cur cur=next
  2. 头插法 p=head.next head.next=cur cur=p
  3. 辅助栈+append
* 链表中环的入口结点：先快慢双指针，记录直到相遇的步数，此时快走了a=x+n(y+z)+y，慢走了b=x+y，a=2b，解得x=n(y+z)+z，因此再用非快慢双指针分别从相遇处和开头出发，开头的走x，环中的相当于走z，就会在环的开头处相遇
  * 当快慢都入环后，慢不可能走x+m(y+z)+y才相遇，即慢必定没走完一圈就相遇。最差情况入环时快比慢多1，慢走到w-1时快走到1+2(w-1)==w+w-1，是同一位置
* 奇偶重排：将偶数位结点移到原奇数位后面。\
  双指针法，空间O(1)：分别用odd和even记录奇偶头结点，遍历时取下原结点加上，最后再把even加到odd后

## 栈和队列

* 用两个栈实现队列：入队列时压栈，出队列时先看另一个栈是否为空，如果非空则直接出栈，如果为空则把第一个栈里的放进去再按前一种情况。关键是再入队时无需把另一个栈放回去
* 用一个队列实现栈pop：将n-1个元素依次出队就立即入队，再出最后一个元素
* 括号（是否）匹配：读到具体的开括号时，push对应回括号，这样else即非开括号只要比较是否与栈顶相等就行了
* 单调队列：滑动窗口的最大值，对于一个长k的窗口，每往后移动一次就汇报一次窗口内的最大值。解法：双端队列，队尾到队首递增。当遇到x时，从队尾抛弃所有小于x的值；当滑出最大值时，出对首。相比于大顶堆(优先队列)，虽然堆也能在遇到大于堆顶时抛弃所有值，但遇到小于堆顶的必须入堆而无法抛弃值

### 单调栈

如保证栈顶到底是递增的，如果新元素大于栈顶，则pop处理。一般存放索引。

两种思想：可以存放“未计算”的对象，往后遍历时如果能够处理了，则弹出。\
第二种思想：存放“已遍历”的内容，继续后续处理时看能不能用上。

#### 接雨水

如[1,0,2,1,1,3]可以接3个水，元素值表示柱子高度。最左右的柱子的外边不存水。

错误想法：先只找高度降低的，再只找高度升高的，就找到了一个坑，按二者中更低的那个确定高度，再坑中每一个位置，累加 坑高-柱高。\
错误原因：如[3,0,1,0,3]，中间的柱子上可以存水。

暴力：对于每个柱子，分别往左右找高度最高的，用 二者中更低的-当前柱高 就是当前柱子上能存的。复杂度O(n^2)

DP：预先计算一个柱子左右两边最高的。方法是用两个数组，分别存放从左边看和从右边看最高的，如左边是ml[i]=max(ml[i-1],height[i])。共3次遍历。

单调栈：一次遍历。与之前思想的重要区别：横向计算。
1. 一开始也是找高度降低的，如果新遍历到的高度小于栈顶，直接把它们的下标存到栈中，即栈顶到底递增。
2. 如果大于栈顶，即找到坑，令mid=st.pop()代表坑底，坑高h=min(height[i],height[st.peek()])-height[mid]，宽w=i-st.peek()-1，横向存水=h*w。
3. 如果当前高度还大于栈顶，则重复上一条计算，即上一条是while。如[3,1,0,2]，先横向计算102，再以1为底横向计算3112。
4. 如果当前高度等于栈顶，应pop再push(i)。包括有坑（[1,0,1]）和无坑（[1,1,0,1]），前者01的雨水算过了，之后要按后面的1算。
5. 实际等于时计算雨水的代码能处理，可以直接入栈，出while时的状态就是<=，因此结构是 for(i<n){ while(栈非空&&当前>栈顶){计算}; push(当前) }

相关问题，盛水最多的容器：仅选两个垂线构成容器，求与x轴组成的最大面积。面积 = (j - i) * min(nums[i], nums[j])。\
解法：双指针分别指向开头和结尾，对应的垂线一个高一个矮。若固定那个矮的，移动高的，只能使得面积变小，因为上式后一项不变。因此解法是不断移动更矮的那个柱子，记录过程中的最大值，直到相遇；相等时动任意一个。

## 动态规划

### 原理

* https://www.zhihu.com/question/23995189/answer/613096905
* 最优子结构：一个问题的最优解包含其子问题的最优解。计算出子问题的最优解后通过状态转移方程计算原问题的最优解
* 重叠子问题：反复求解相同的子问题；同时也是与分治的区别
* 无后效性：后续决策不受历史决策过程影响，只依赖状态，不依赖到达此状态的步骤。如最长路径不具有最优子结构的性质。要求出解决问题使用了某一种方式不行，只求结果可以

### 步骤

自底向上：

1. 确定dp数组及下标的含义。一般dp[i]表示问题中的值等于i时的结果
2. 确定递推公式。如依赖 dp[i-1]、max(dp[i-1], 直接算)、max(dp[前面所有])
3. 初始化dp数组。如对于图，初始化第一行和第一列。根据已知条件把显而易见的算出来
4. 确定遍历顺序。包括一维从前往后还是从后往前，二维内外层循环先用哪个。按一种方向把剩余的填充
5. 举例推导dp数组。在纸上算几项是否正确

记忆化递归：def dfs()加@cache，写值等于0时的出口，写if ... return dfs(...) + dfs(...)。在问题中调用dfs(i=n)

常规化的定义：用dp[i]表示对于nums[0..i]满足“问题”的结果。假如已知dp[i-1]，分类讨论如何算出dp[i]，最后返回它即可。

常见问题：求总数，当前项来自于多种过去计算的，累加。求最大或最小值：取已计算的满足最优解的那一项，再加上本次。

加法原理：如果事件A和事件B是互斥的（即不能同时发生，不选nums[i]的同时，又选了nums[i]），那么发生*事件A或事件B*的总数等于事件A的数量加事件B的数量。

### 例子

* 使用最低花费爬楼梯：每一层楼梯有cost[i]，支付那层费用后才能爬上去，之后可选择爬一层或两层；初始也可选择爬一层或两层；结尾若爬到倒数第2层，则下一次不算费用

  * 如果中间有“石头”不可到达，则那个位置设为0。如果石头在第一行或第一列，初始化时**后续位置也要设为0**
* 整数拆分：将n拆分成至少2个整数，使其乘积最大

  * 钢条切割：不同长度的钢条价格不同，求收益最大化。4的最优解=max(1的价格+3的最优, 2价格+2的最优, 3的价格+1的最优)。即一刀有多个点位，左边的不再分，右边的继续分

### 编辑距离(Levenshtein Distance)

* 两个字符串之间，由一个转换成另一个所需的最少编辑操作次数。允许的编辑操作包括：替换、插入、删除 一个字符
* 以两个字符串A、B为例，A[0,5]表示闭区间
* 自顶向下
  * 当最后一个字符相同时不需要转换，相当于删除两者最后一个字符且不增加步数。abb ab 和 ab a 之间有相同的编辑距离，A[0,2] B[0,1] == A[0,1] B[0,0]
  * 当最后一个字符不同时
    * “替换”操作相当于删除A B两者最后一个字符，因为将两者最后一个字符替换统一后就变成了上一种情况
    * 插入相当于删除B的最后一个字符，因为目标是从A变到B，给A插入B的最后一个字符后就变成了上上种情况。删除是删除A的最后一个字符。操作完后，两者最后一个字符仍可能不同，递归处理
    * 当前步骤的最小编辑距离就是上面三种操作的最小值+1
  * 出口条件：当A B任何一个为空时，编辑距离为另一个字符串的长度
* 自底向上
  1. 以dp[i][j]表示从A[0,i]变换到B[0,j]的最小编辑距离
  2. 对于A[0,0]即空字符串变到B[0,j]，即dp[0,j]，每一步都是插入；对于A[0,i]变到B[0,0]，即dp[i,0]，每一步都是删除
  3. 对于dp[i][j]，当A[i]和B[j]相等时，取dp[i-1][j-1]，否则取min{左边，上面，左上角}+1
  4. 最后的结果就是dp[n][m]

### 买卖股票的最佳时机

一个数组prices[i]表示一支股票在第i天的价格。

* 只能买卖一次：每天都试图卖出，且是按在此之前的最低点买入的（或理解为假如出现新的低点，就按低点买入），但结果要取整个过程中可能的最大值。low=min(low,price[i]); profit=max(profit, prices[i]-low) 初始low=INT_MAX
  * 不是 最低点买入，在此之后的最高点卖出，更不是max-min。如[5,9,1,2]。可以差分再按最大子数组和
* 可以无限次买卖：每次上升前买。差分后取所有>0的求和

最多买卖两次、最多买卖k次、任意次数但卖出后无法在第二天买（冷冻期）、任意次数但卖出时要支付固定额度的手续费：用dp:list[(a,b]]记录，dp[i]表示第i天。

如买卖一次，dp[i][0]表示第i天持有股票时的最大剩余金额=max(dp[i-1][0]即前一天也持有股票, -prices[i]即前一天未持有今天买入)。\
dp[i][1]表示第i天不持有股票时的剩余金额=max(dp[i-1][1], price[i]+dp[i-1][0]即前一天持有今天卖出)。\
初始化dp[0][0]=-prices[0]表示买入。结尾返回dp[-1][1]。\
如无限次买卖，dp[i][0]=max(dp[i-1][0], dp[i-1][1]-price[i]即加上前一天卖出剩的钱)。

如买卖两次，一天的状态变为 从不操作 第一次买 第一次卖 第二次买 第二次卖。其中后几项不代表要在当天这么操作，而是状态。初始化dp[0][1]=dp[0][3]=-prices[0]，后者表示第一天买了卖了再买。

## 背包问题

背包有个总容量，不大。每件物品有各自的重量w、价值v。\
如果一件物品只能用一次，叫01背包。如果能反复用，叫完全背包。不同物品数量不同叫多重背包。每组只能选一个，叫分组背包。

常见问题类型：求背包能装满的最大价值。背包是否能刚好装满。用最少的数量刚好装满。有几种方案装满。

### 01背包

* 二维dp数组：dp[i][j]表示考虑了编号为[0..i]的物品（不知道具体哪个选不选），背包重量为j时，的最大价值
* 公式：遍历每个物品和背包容量值，dp[i][j]=max(dp[i-1][j], dp[i-1][j-w[i]] + v[i]) 前者即选择不放i，保持价值不变；后者即放i，对于当前背包容量j来说尽量占满
* 初始化：第一列即背包容量为0时价值全为0，第一行当背包容量大于重量时设为value[0]
* 遍历顺序：也可以先遍历(外层循环)j，即先计算对于某个容量依次放各个物品的最大价值，按列填充。因为公式不变，数据还是来自于左上方
* 一维滚动数组：因为dp[i]仅依赖于dp[i-1]，可改为只保留dp[j]=max(dp[j], dp[j-w[i]]+v[i])，表示当容量为j时的最大价值。仍二重循环，但**必须先遍历i，且j必须从后往前遍历**，每轮只需更新到j>=w[i]
  * 若j从前往后遍历：从公式上讲，本应使用二维中的dp[i-1]变为了dp[i]，或者说覆盖了。从原理上讲，会导致重复选取物品，因为dp[i]表示的最大重量中可能已经存在v[i]了

#### 例子

* 分割等和子集：如[1,5,11,5]可分成[1,5,5]和[11]。解法：将值视为重量，刚好装满容量为 sum/2 的背包
* 一和零：一个list[str]其元素只含有任意个1和0，取一个子集含有最多m个0和n个1，求它的元素个数
  * 解法：具有2个维度限制的01背包，元素0和1的个数视为重量，最外层遍历物品i
j二重循环从大往小遍历，dp[i][j]=max(dp[i][j],dp[i-zeroNum][j-oneNum]+1)
* 目标和：一个非负整数arr，里面每个元素可添加+或-，使其计算结果为target（可负）。求有几种方案
  * 若将一种解中添加+的元素划为集合x，添加-的划为neg，则target=x-neg。又可以另外计算数组总和sum=x+neg，消去neg，得 x = (target+sum) / 2，右边都是已知固定的，变为求容量为x的背包问题
  * 如果target+sum是奇数直接返回无解。其实也可以消去x，求neg=(sum-target)/2，当sum-target<0或是奇数时直接返回无解
  * 初始化：当x=0时，有且仅有1种方案，即都不选。dp[0]=1
  * 递推公式：dp[j]+=dp[j-nums[i]]，外层遍历物品i以保证不会重复选，每个容量都尝试用物品i装，累计装满当前容量的方案数

### 完全背包

* 就是一维01背包j从前往后遍历，从w[i]开始。也可以先遍历j再遍历i，表示对于每一个容量都将所有物品试一遍，仍从前往后。不适合二维数组，要在上一层计算多个容量放多个w[i]取最大值
* 找钱问题：如面额为11、5、1，找15，用最少张数。`数量 dp[金额]`，dp[j]=min(dp[j], dp[j-w[i]]+1)；初始化dp[0]=0，dp[其他]=INT_MAX；如果最后dp[amount]==INT_MAX则表示凑不出。RMB可用贪心，因为小面额一定“兼容”大面额

* 单词拆分：一个字符串s，一组单词，判断s能否由单词构成。dp[j]表示s[0:j+1]是否可被拆分，dp[0]=True。遍历每一个容量，再从后往前依次取后缀子串，如果在词典中且前面为True，则当前设为True且break

## 贪心算法

* 特点
  * 局部最优解(做“最合适的”选择)就是全局最优解(问题目标如数量最大)：每次选择分支的时候，只要选择一个分支，这个分支的解就一定比其他选择更优。如果想不到反例就可以试试
  * 无状态（DP的当前状态是由上一个状态推导的）。不会重新选择（回溯）
* 跳跃游戏（类似于灯的覆盖范围）：一个数组，其元素表示可以往后移动的最大长度，一开始处于开头，要求判断是否能到达结尾
  * 解法：不断增加“覆盖”范围，不需要管是如何过来的。for(int i=0;i<=cover;i++) cover=max(i+nums[i], cover) 注意不断改变边界cover
  * 使用最少的跳跃次数（题目保证一定能跳到）
    * 方法一，反向处理，寻找i+nums[i]>end的最小i，因为那样的i可以覆盖之后的所有位置，不必选那些；找到后将i作为新的end，继续往前。复杂度O(n^2)
    * 方法二：正向处理，遍历整个nums（除最后一个元素没用），在当前能移动的范围中（假定没到终点），记录下一步能移到的最远位置，当i移动到当前范围end时，计1步，将那个最远位置作为新end。不是直接选下一步能移动到最远位置的那一步，因为再下一步可能在它前面（所以要依次遍历），但至少它有能力移动到前面的任意位置
* 分发糖果：给一个rating数组，若i的分数比左右更高，则它要拿更多的糖果。如[1,0,1]分别发[2,1,2]，[1,2,2]发[1,2,1]，[1,2,2,1]发[1,2,2,1]
  * 解法：两次遍历。先从左往右处理一次 left[i]=r[i]>r[i-1]?left[i-1]+1:1，再从右往左处理一次，结果为max(left[i],right[i])。实际right只需一个变量记录即可
  * 解法二：若当前处于上升，则是前一个+1。否则直接设为1。但还会受右边的影响，继续往后遍历，若又处于新的上升，则与前面一样；若处于下降序列中，每多一个元素，对前面下降序列的元素都+1。另外当这个下降序列长度与前一个上升序列长度相等（且二者相邻处分数不等）时，还要将上升序列最后一个纳入下降序列，如[1,2,3,2,1,0]发[1,2,4,3,2,1]；实际上若相邻处分数相等，后者默认属于上升队列但长度重置为了1，若下一项下降，则会按前一条纳入

## 回溯 Backtracking

def product(*list_of_iter): # 给定多个集合，从每个集合中各选出一个元素，每个组合的长度为集合个数，所有组合的个数为各集合长度相乘
    '''('ABCD', '123') -> A1 A2 A3 B1 B2 B3 C1 C2 C3 D1 D2 D3'''
    if not list_of_iter:
        yield ()  # 不能 ret ((),) 因为本函数存在yield会被编译成生成器，而用for迭代生成器时遇到ret会隐式吃掉返回值
        return
    first, *rest = list_of_iter
    for item in first:
        for prod in product(*rest):  # 可改为 yield from ((i,)+p for p in ...)
            yield (item,) + prod
# 循环算法：类似reduce，分为result和cur，每次类似于result @= cur
```

排列：

```py
def permutations(l): # 从一个集合中选出r个元素，且考虑元素的顺序。算法：从当前集合中选一个元素 合并 递归(剩下的元素)
    '''全排列：123 -> 123 132 213 231 312 321'''
    if not l: # 若用r，改为if r==0
        yield (); return
    for i,e in enumerate(l):
        rest = l[:i]+l[i+1:]
        for perm in permutations(rest): # r-1
            yield (e,) + perm
# 先序风格
result = []
def permutations(l, path=()):
    if not l:
        result.append(path); return # 在叶子处聚合结果
    for i,e in enumerate(l):
        rest = l[:i]+l[i+1:]
        permutations(rest, path + (e,)) # 不能写在外面+=，因为回溯时要还原状态
```

* 组合：rest=l[i+1:]即可。对某个元素如果选了就选，如果不选后续不再选；实际上固定了一种顺序，结果中的元素一定按顺序对应原集合，不会逆序。如果r固定，可改用r重循环，每一层从上一层的index+1处开始；而排列却不方便这么改
* 有放回组合（又称with replacement）：rest=l[i:]即可，即也可以选当前位置
* 组合剪枝：循环条件 i<n-r，即保证至少剩r个数，如(1,2,3,4) r=3，若第一轮i到了1，后续只能取3,4，若到了2，后续只剩4，不够取到r了
* 子集：在先序风格的组合中循环前append(path)，即在遍历过程中返回当前结果。循环算法：类似reduce，初始已有result=[()]，每取一个元素，与每个现有元素组合一遍，添加进result，重点是result中已有元素没有更改；或者按不可变的说法，每取一个元素将返回 已有元素 和 已有元素+当前元素 两个结果

  * 解法二：拆分成 '({left}){right}'，依次回溯 0+3+1 1+2+1 2+1+1 3+0+1。原理：任何有效结果必以开括号开头，中间一段有效结果，结尾一段有效结果（可为空）。也是卡特兰数的递推公式
* 切割：分成 头和剩下，头要满足某些条件，单次分有多种点位可选，一份结果“合起来”刚好是整体，求所有结果。如“复原IP地址”："25525511135"->[11.135 111.35]
* 八皇后要点
  1. 对于每一行，回溯(行+1,所有列)。这样行天然不重复。当行==n时则解数+1。
  2. 记录已放位置：不需要n×n二维数组。只需用长度为n的一维数组 `列 pos[行]`。
  3. 判断不在同一列和斜线：①r+c可唯一确定反斜线，r-c可唯一确定正斜线。②abs(r-i)==abs(c-pos[i]) 可同时确定正反斜线，即两点横坐标距离等于纵坐标距离

## 遍历图

* 岛屿数量：二维数组，用1表示陆地，0表示海洋；相邻的1算一个岛。解法：在遍历一个岛时，把走过的地方设为0。迭代每个位置即可
* 最长递增路径长度：如[[1,2],[4,3]]有1->2->3->4，答案为4。如果按回溯的思想，从头(算1)数到尾，会超时。正解：算“深度”并记录，即尾的深度为1，往回加，一个位置的最大深度是不变的，算过了不用重算
* 二维数组从上到下递增，从左到右递增，查找给定的数t：只保证了左上小于右下，若当前值小于t，则t可能在右上、右下、左下；若大于，则在右上、左上、左下。正解：从最右上开始处理，若小于，则在左边，若大于，则在下面

## 区间

* 区间合并（贪心）：如(1,2),(3,4)->(1,4)。先按左边界排序。若 arr[i]的右边界 > arr[i+1]的左边界，则重叠。遍历更新“当前区间”的右边界，当不重叠时加入结果；最后一个元素要额外判断是否合并了。统一处理方式：先把第一个元素加入结果，后面每遍历一个元素，更新结果中最后一个元素右边界
* 区间完全覆盖：给定一些(闭)区间，要求用最少的数量完全覆盖1~n，若无法完全覆盖则输出-1。
  * 先排序，如果第一项都不以1开头，则必无法完全覆盖；之后“当前区间”就只用考虑右边界了。继续遍历，在那些 左边界 < 当前右边界 的区间中，仅取一个最大的右边界，再继续
  * 方法二：处理每一位置。用next[i]表示当下标为i时最远覆盖的地方。初始化遍历所有区间，next[i]=max(next[i],end)，即若存在(1,2) (1,3)这种同一起点时优先选end大的。再遍历每一位置，维护一个窗口，在窗口内寻找最远处，窗口结束时计数+1。初始i=0,end=last=next[i]，在(i,end)遍历更新last=max(last,next[i])；如果遇到i==last说明无法往后扩展，返回-1；当遇到i==end，count++，end=last
  * 错误想法：按能覆盖最长的区间排序，取了一个后要与已存在的区间合并，还要对每一个剩下的区间消去取的
* 用最少次数去除重叠区间(射爆气球、区间选点)：如(10,16),(2.8),(1,6),(7,12)，在x=6时去除(2,8),(1,6)，在x=11去除剩下两个
  * 解法（贪心）：先按左边界排序。因为最终一定要消除所有区间，最晚当遍历到任何一个右边界时，执行消除，能一次性消掉最多重叠的
  * 技巧：只需记录最小右边界，如一开始(1,5)，则记录5，下一条(2,4)，则最小右边界为4，若下一条(6,7)，则count++，最小右边界为7
* 最大(多)不相交区间数：https://www.cnblogs.com/acgoto/p/9824723.html
* 打点标记法处理整数区间：如24小时对应int[24]，未公开对应0，公开且空闲对应1，占用中对应2

## 树状数组/二叉索引树(BIT)

* 可解决大部分区间上的修改和查询的问题。如 1.单点修改，单点查询。2.区间修改，单点查询。3.区间查询，区间修改（太复杂，不方便，改用线段树）
* 高效计算数列的前缀和、区间和。以O(logn)的时间得到任意前缀和；单点值的修改也变为O(logn)
* 线段树能解决的问题，树状数组大部分也可以，反之则不行。树状数组更简单，线段树扩展性高

### 相关函数

```
int lowbit(int x) { return x & (-x); }
返回数字x最低位的二进制1及后面的0代表的数字，如lowbit(3)==1, lowbit(4)==4, lowbit(2)==lowbit(6)==2。原理：-x等于取反+1
特性：对于B[i]，lowbit(i)就是它代表的区间的长度

求前缀和：从后往前累计当前区间的值，减去区间长度递归调用
int count(int p) { // 或叫ask
    if (p==0) return 0;
    return B[p] + count(p - lowbit(p))
}

（原数组）单点增加：B[i]的上一层是B[i + lowbit(i)]，依次修改每一层
void add(int p, int x) {
    while (p < N) {
        B[p] += x;
        p += lowbit(p);
    }
}
```

### 使用

* 单点查询：ask(x) - ask(x-1)
* 区间查询：ask(r) - ask(l-1)
* 创建前缀和树状数组：循环 add(i, A[i])。本质上A和B是等价的，此语句相当于B[i]=A[i]
* 区间修改，单点查询
  1. 对于原数组a，创建差分数组b，再创建树状数组维护b的前缀和，结果上使得a[i]==ask(i)
  2. 当要做a[l:r]+=d：add(l,d); add(r+1, -d)，即变为差分数组的单点修改。单点查询时返回ask(i)
  3. 改进思路：创建一个初始全为0的“蒙版数组”，再创建它的差分数组当然也是全为0，再维护前缀和；结果上使得不必创建前两者，就用前缀和内置的数组代替了，使得ask(i)的值是对a[i]的修改值，单点查询返回a[i]+ask(i)
* 普通前缀和：与朴素做法相比，查询O(1)，修改O(n)
* 普通差分：题目先多次修改（可区间）完再查询，没要求混着做。修改时类似上面的。等要查询时做一次前缀和变回原数组，如果要求多次查询区间再做普通前缀和

def evens():
    '''从3开始的无限奇数序列'''
    x = 3
    while True:
        yield x; x += 2
def primes():
    '''无限素数序列'''
    yield 2
    nums = evens() # 待处理的无限序列
    while True:
        n = next(nums); yield n
        nums = (x for x in nums if x % n != 0) # 去掉序列中n的倍数。生成器是惰性的，n会被捕获；赋值给自己达到链式过滤的效果
